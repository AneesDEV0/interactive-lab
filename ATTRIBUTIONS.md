The application loads its scripts, fonts and geometry data locally. It contains no remote model viewer, CDN import or external image request.

No third-party 3D model is included. The initial asset search and rejected candidates are recorded in [asset-research.md](docs/asset-research.md). Search results are not treated as successful downloads. A partial Kenney archive failed validation and was removed.

The original educational models deliberately provide **one AA compartment** each for the toy car and portable radio. The refrigerator is a home refrigerator in the simulation. Display scales differ for visibility; physical size does not determine compatibility.

The app's source and documentation are provided with the project. The CC0 dedication above applies to the original artwork; third-party licenses remain separate.

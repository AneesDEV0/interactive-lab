# مختبر شرارة — وحدة الكهرباء للصف الرابع

موقع عربي متجاوب للأطفال: جهاز واحد في كل تجربة، وضع **تعرّف** للمشاهدة والمعلومة، ووضع **جرّب** لاختيار مصدر الطاقة ومشاهدة النتيجة. يضم الأجهزة السبعة عشر الظاهرة في صور الكتاب المرفقة، ومساعدًا تعليميًا محليًا مع ٩٨ مقطع توجيه عربي.

## التشغيل

```powershell
npm ci
npm run dev
```

افتح http://127.0.0.1:4173. مكتبات التشغيل والخطوط والمجسمات والصوت محفوظة محليًا؛ `npm ci` مطلوب لأدوات التطوير والاختبارات فقط. يتطلب الخادم Node.js 20+.

```powershell
npm run build
npm run preview
```

أوقف خادم التطوير قبل تشغيل المعاينة على المنفذ نفسه. مجلد `dist` جاهز للاستضافة الثابتة. لم تُنشر النسخة إلى استضافة خارجية.

## ما يستطيع الطفل فعله

- اختيار جهاز من مكتبة صور الكتاب، تدوير مجسمه وتقريبه، أو فتح باب الثلاجة.
- سماع وقراءة معلوماته في «تعرّف»، وتجربة البطارية والكهرباء في «جرّب».
- تجربة الشمس للسيارة الشمسية، والرياح للعنفة، وحركة العجلة للدينامو.
- التصوير بالكاميرا أو اختيار صورة؛ تُطابَق صورة الكتاب محليًا باستخدام OpenCV، ويؤكد الطفل الاسم قبل فتح المجسم. عند عدم التأكد، يختار الجهاز بنفسه.
- تجربة AR على سطح مكتشف بالهاتف المدعوم، أو VR مع أزرار ثلاثية الأبعاد ومؤشر النظارة.
- طلب تلميح أو سؤال شرارة، ثم مراجعة اكتشافاته المحفوظة على الجهاز.

## حدود التشغيل

الصورة تُطابَق بمجسم جاهز. سبعة مجسمات محمّلة من Kenney بترخيص CC0، والبقية نماذج تعليمية محلية أو معاد استخدامها من المشروع. الصوت مسجل بصوت عربي عصبي ويعمل بعد تفاعل المستخدم؛ يوجد بديل صوت عربي من الجهاز، وتظل الكتابة متاحة عند فشله.

AR وVR يحتاجان متصفحًا وجهازًا متوافقين ورابط HTTPS على الهاتف. AR يستخدم WebXR hit-test وDOM overlay؛ لا نسمي صورة كاميرا خلف مجسم واقعًا معززًا مثبتًا. أُنجز التنفيذ وفُحصت حالات عدم الدعم، لكن لم يتوفر هاتف AR أو نظارة لاختبار التتبع والأزرار ميدانيًا.

المساعد محاكٍ تعليمي محلي ذو إجابات معدّة، وليس LLM عامًا. لا مفتاح API. لا تُرفع صور الطفل أو أسئلته. لا ضمان لإعادة فتح الموقع دون إنترنت، لأن الموارد الثقيلة تُحمّل عند الحاجة.

## البنية والاختبارات

الواجهة الجديدة في `src/electricity/`، ومدخلها `index.html`. مداخل `static-lab.html` و`dynamic-lab.html` والمداخل القديمة تحت `public/` تتجه إلى وضعي الواجهة الجديدة. ملفات التجربة القديمة محفوظة لتسهيل المقارنة، وليست مدخل الموقع الحالي.

```powershell
npm test
npm run test:browser
```

اختبار المتصفح يحتاج خادمًا يعمل وChrome مثبتًا. النتائج واللقطات في `docs/redesign/`. للمراجعة: `docs/redesign/DESIGN.md` و`docs/redesign/browser-results.json`.

إعادة توليد الصور المصغرة بعد تشغيل الخادم: `npm run assets:thumbnails`.
إعادة توليد النصوص الصوتية: `npm run audio:manifest` ثم `python scripts/generate-electricity-audio.py` بعد تثبيت `edge-tts`. توليد الصوت يستخدم اتصالًا خارجيًا وقت التطوير ويرسل النصوص التعليمية فقط؛ الاستخدام اليومي يشغّل الملفات المحلية.

راجع `ATTRIBUTIONS.md` للمصادر والتراخيص.

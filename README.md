# مختبر شرارة — Battery & Devices Lab

تجربة تعليمية عربية تفاعلية للأطفال 6–9 سنوات، مع خيار 4–6 بمساعدة بالغ. **HTML وCSS وJavaScript فقط**، دون React أو إطار واجهة أو bundler. تستخدم Three.js المحلية للرسم الثلاثي الأبعاد.

## التشغيل

من مجلد المشروع:

```powershell
node scripts/server.mjs
```

افتح **http://127.0.0.1:4173**. لا يلزم `npm install` لتشغيل النسخة المسلّمة: المكتبة والخطوط موجودة محليًا. يتطلب الخادم Node.js 20 أو أحدث. يمكن أيضًا تقديم الملفات بأي خادم static يدعم ملفات JS وWOFF2؛ لا تفتح `index.html` مباشرة عبر `file://` لأن النشاط يستخدم وحدات JavaScript وقراءة JSON محلية.

لإنشاء نسخة static جاهزة للنسخ إلى استضافة:

```powershell
npm run build
node scripts/server.mjs dist
```

أوقف الخادم الأول قبل تشغيل الثاني على المنفذ نفسه. البناء ينسخ الملفات ويحسب الحجم؛ لا يستخدم framework. لم يُنشر المشروع إلى استضافة خارجية.

## رحلة الطفل

1. ابدأ وتخطّ الشرح إن أردت.
2. اختر البطارية ثم الجهاز، أو اسحبها إلى المجسم أو بطاقة الجهاز. كل الأجهزة تظهر كأهداف محايدة.
3. التوقع اختياري، ولا يحول دون التجربة.
4. السيارة والراديو الافتراضيان مصممان للخلية الواحدة المعروضة. نقلها يوقف الجهاز السابق، ويحفظ اكتشافك.
5. لا تشغّل البطارية الصغيرة ثلاجة المنزل. بعد هذه الملاحظة يتاح عرض التغذية المنزلية الذي يقوم به شرارة، الروبوت البالغ، افتراضيًا.
6. دفتر الاكتشافات يفصل حالة التشغيل الآن عن النتائج التي شاهدتها. بعد أربع ملاحظات يتاح التصنيف وسؤال التفسير، ثم الشارة.

لا عدّ تنازلي ولا عقوبة للمحاولات. كلا المصدرين يزوّد الجهاز بالطاقة الكهربائية. لا توجيهات لتوصيل مقابس حقيقية.

## المساعد والصوت والخصوصية

- شرارة محرك نوايا ومعرفة محلي، بإجابات جاهزة تتغير مع الحالة. لا API ولا مفتاح ولا اشتراك.
- يدعم مرادفات عربية وبعض الإنجليزية والتشكيل والهمزات، ويطلب توضيحًا عند غياب السياق. ليس مساعدًا عامًا ولا يفهم كل صيغة ممكنة.
- النص الحر يعرض كنص آمن، ولا ينفّذ أوامر أو HTML.
- الصوت مكتوم افتراضيًا. عبارة الراديو تُنشأ بـWeb Audio بعد تفاعل. النطق اختياري عند وجود صوت مطابق للغة في المتصفح. غياب الصوت لا يؤثر في النتيجة.
- لا أسماء أو صور أو تحليلات أو حفظ محادثة إلى خادم. `localStorage` يحتفظ بتفضيلات الصوت واللغة والحركة والعمر فقط. إعادة البدء تمسح سجل الجولة والمحادثة، وتحتفظ بالتفضيلات.
- واجهة عربية RTL وإنجليزية LTR قابلة للتبديل من الإعدادات. النصوص في `src/config.js` و`src/knowledge.js`.

## الاختبارات

```powershell
npm test
```

اختبارات Node لا تتطلب تثبيت مكتبات. لاختبار المتصفح، بعد تشغيل الخادم:

```powershell
npm ci
npm run test:browser
```

يستخدم الاختبار Chrome المثبت وPlaywright للتطوير فقط. يحفظ النتائج في `docs/browser-results.json` واللقطات في `docs/screenshots/`. لا يدخل Playwright أو agent-browser في النسخة التي يشغّلها الطفل.

النتائج والقيود موثقة في `docs/VERIFICATION.md`. الحالات المختبرة تشمل التوافق، النقل، الرفض، العرض المنزلي، إلغاء السحب، إسقاطًا خارج الهدف، منع الإتمام المبكر، الأسئلة الغامضة والمتكررة، reset، حقن HTML، فشل أصل حقيقي وفقد WebGL، التفاعل باللمس ولوحة المفاتيح والاتصال المقطوع بعد التحميل.

## الإتاحة والأداء

- الأزرار 48px على الأقل، وحالة التشغيل مكتوبة، مع بديل HTML للمجسمات و`aria-live` ورسائل قصيرة.
- Tab وEnter لجميع الأفعال؛ Escape يغلق الحوار/الدردشة ويلغي حمل البطارية. الحوارات تستخدم `<dialog>` مع إدارة التركيز.
- تقليل الحركة يوقف مسار السيارة وحركة العجلات والتلميح المتحرك، ويبقي مؤشرات التشغيل.
- تكبير موجّه وفحص وزر إعادة الكاميرا. على الهاتف الأزرار تبقى تحت المشهد، والدردشة لوحة سفلية قابلة للإغلاق.
- دقة الرسم محدودة، وخرائط الظلال يعاد حسابها عند تغير الحالة. ينخفض pixel ratio إلى 0.8 عند ملاحظة معدل أقل من 22fps. القياسات الفعلية وحدودها في تقرير التحقق؛ لا ندّعي ضمان 30fps على هاتف لم نختبره.
- بعد اكتمال تحميل الموارد، اختُبرت متابعة الجولة دون شبكة. **إعادة فتح الصفحة offline غير مضمونة**؛ لا يوجد service worker ولا وعد بذلك.
- تحديث الصفحة يبدأ جولة جديدة. تدوير الشاشة وفتح المحادثة لا يفقدان التقدم.

## إضافة جهاز أو سؤال

لإضافة سؤال: أضف قاعدة بـ`id`, `patterns`, `ar`, `en`, `examples` إلى `knowledge.js`، واستخدم resolver ديناميكيًا إذا احتاجت الإجابة دليلًا من الحالة. لا تضع ادعاء «جرّبت» في نص ثابت. اختبار الأمثلة يعمل تلقائيًا؛ أضف أيضًا اختبار نفي أو التباس مستقل.

لإضافة جهاز: أضفه إلى `config.devices` وأسماء اللغتين، ثم حدّث initial device maps وقواعد التوافق في `state.js`، والمجسم والحجرة في `scene.js`، والاكتشافات وشروط التصنيف والواجهة في `main.js`. أضف اختبارات المصدر الصحيح، الخاطئ، نقل البطارية وإتمام الرحلة. القائمة الحالية ذات ثلاثة أجهزة مقصودة وليست محرر أجهزة عامًا.

لإضافة provider آخر مستقبلًا: حافظ على استجابة `intent/text/suggestedActions/referencedEventId/stateRevision`، وعلى تحقق الإجراءات في العرض والتنفيذ، ومرّر `sessionRevision` لكل جواب مؤجل. التنفيذ الحالي مكتمل بالمحرك المحلي.

## حدود واضحة

المجسمات الأصلية تعليمية، وليست نماذج كهربائية رقمية أو منتجات تجارية موثّقة المتطلبات. هدفها فهم توافق المصدر والتصميم. لا نحاكي نفاد البطارية أو قطبية خاطئة أو أعطالًا عشوائية. لا توجد بيانات طفل أو نقاط قابلة للزيادة بالتكرار. زمن 5–8 دقائق تقدير تعليمي من الطلب؛ لم يُقَس بجلسة مستخدمين أطفال.

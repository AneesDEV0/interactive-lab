# مختبر شرارة — علوم الصف الرابع

منصة عربية RTL بأربع تجارب: شغّل الأجهزة، افرز المواد، اختر التصرف الآمن، واختبر مرور الكهرباء. احتُفظ ببنية JavaScript وThree.js والأصول المحلية؛ لا Backend أو API أو خدمة AI وقت التشغيل.

## التشغيل

```powershell
npm ci
npm run dev
```

افتح http://127.0.0.1:4173. في نافذة طرفية أخرى:

```powershell
npm test
npm run test:browser
npm run test:camera
npm run test:xr
npm run build
```

الاختبارات تحتاج Chrome وخادمًا يعمل. الكاميرا الاختبارية اصطناعية؛ اختبار XR منطقي وليس اختبار أجهزة حقيقية. لتجربة البناء أوقف خادم التطوير ثم شغّل `npm run preview`.

## البنية الحالية

- `index.html`: أربع بطاقات وتقدم حقيقي. `about.html`: الحقوق والمعلومات التقنية ومسح التقدم بتأكيد.
- `electricity.html`, `materials.html`, `safety.html`, `conductors.html`: مداخل الأنشطة؛ تستعمل `src/shared/app.js` و`lab.css`.
- `src/shared/catalog.js`: بيانات التحدي والتقييم وبنك الإرشادات مشتقة من بيانات الأنشطة الأصلية.
- `learning.js`: انتقالات الحالة، التلميحات، النجاح بمساعدة، والحفظ الآمن.
- `components.js`: ActivityLayout وItemPicker وShararaAssistant والحوارات.
- `audio-manager.js`: مالك واحد للصوت؛ تسجيلات الموقع وقراءة الجهاز خياران منفصلان في إعدادات الصوت. لا تبديل تلقائي بينهما، ولا ميكروفون أو TTS خارجي.
- `camera.js`, `references.js`: تصوير ومعاينة ومطابقة مناطق محددة من صور الكتاب ثم تأكيد. لا رفع صور.
- `model-viewer.js`: يعيد استخدام مشهد الكهرباء وWebXR والمجسمات الموجودة، مع تحسين الكاميرا والحجم وإزالة منصة العرض.
- ملفات الواجهات القديمة باقية للمراجعة؛ مداخلها القديمة تحوّل إلى المداخل الحالية.

التقدم في `sharara-progress-v3`، والمساعدة في `sharara-attempts-v3`، والصوت في `sharara-sound`. تُرحّل النتائج الصحيحة من مفاتيح الأنشطة السابقة، ولا يُحسب النجاح المتكرر إنجازًا جديدًا.

## الحدود والأصول

التسجيلات المتاحة مولّدة مسبقًا، وليست بشرية. العبارات بلا ملف مطابق تبقى مكتوبة؛ يمكن اختيار قراءة الجهاز صراحةً. لا ندّعي أن إعدادات السرعة تجعل النبرة بشرية. دليل تسجيل بشري مستقل في `assets/audio/narration/manifest.json`، ونصوص التسليم في `docs/audio/recording-script.json`؛ توليدها بـ `npm run audio:script` لا يتصل بأي خدمة ولا ينتج صوتًا. راجع `docs/audio/RECORDING.md`.

المطابقة المحلية في `src/electricity/recognition.js` تتحقق من الملامح والهندسة. يوجد ١٧ مرجع أجهزة و٥ مناطق سلامة و٩ مناطق مواد (٨ منها للخامات). ليست فهمًا عامًا للصور، ولا تنشئ مجسمًا من الصورة.

عُزلت الطباشير من تحدي الخامات لأن البيانات الأصلية تصنفها خشبًا، وموقف إصلاح السلك بالشريط من تحدي السلامة لحين مراجعة مرجع موثوق. بقيا في الملفات الأصلية. التحديات الحالية: ١٧ جهازًا، ١٤ خامة، ١٣ موقفًا، ١٥ مادة.

AR/VR الحقيقيان في نشاط الأجهزة فقط، بعد فحص الدعم. AR يتطلب hit-test وDOM overlay وجهازًا واتصالًا آمنًا مناسبين. بقية الأنشطة تستخدم عرض الشاشة. لا ضمان للعمل الكامل دون اتصال.

راجع [تقرير التنفيذ](docs/implementation/REPORT.md) واللقطات والنتائج في `docs/implementation/`. مصادر الأصول وتراخيصها في `ATTRIBUTIONS.md`.

# تقرير التنفيذ — مختبر شرارة

**٩ أكتوبر ٢٠٢٦.** تنفيذ Frontend محلي ببنية المشروع الحالية، دون تبعيات أو خدمة خارجية جديدة.

## أثر التغييرات

- رئيسية بأربعة أنشطة فعلية وتقدم حقيقي وزر متابعة. البحث والحقوق في «عن المنصة».
- قالب مشترك، صور مصغرة بدل مشاهد متعددة، عنصر كبير وخيارات ملاصقة. زر «التالي» بدل الانتقال التلقائي.
- لا مصدر مختار مسبقًا؛ أسماء خامات محايدة؛ لا شارات صواب أو خطر وهالات تكشف تصنيف الموقف قبل المحاولة.
- الفرز بالنقر ولوحة المفاتيح وبطاقة سحب مستقلة عن المجسم. الموصلات تعرض دائرة ومصباحًا قبل طلب الاستنتاج.
- تفسيرات مرتبطة بالعنصر، تلميحات متدرجة، وأسئلة فهم. النجاح بمساعدة محفوظ داخليًا دون إحراج الطالب، والتكرار لا يضاعف الإنجاز.
- RTL وخط عربي محلي، تركيز مرئي، لمس ٤٤ بكسل أو أكثر، وبديل عند تعذر WebGL أو التخزين.

## الصفحات والمكونات

المداخل: `index.html`, `electricity.html`, `materials.html`, `safety.html`, `conductors.html`, `about.html`؛ وتحويل المداخل السابقة تحت `public/`.

في `src/shared/`: ActivityLayout وItemPicker وShararaAssistant في `components.js`؛ الإجابات والنتائج في `app.js` و`learning.js`؛ البيانات وبنك الإرشاد في `catalog.js`؛ وModelViewer وCameraCapture وAudioManager. التصميم في `lab.css`.

أُعيد استخدام مجسمات الكهرباء والخامات والسلامة ومشهد الكهرباء وWebXR، مع تحسين موارد WebGL والكاميرا والخامات وتدريجات المسطرة. المصغرات الأصلية محفوظة؛ نسخ التحدي المحايدة في `assets/thumbnails/challenge/`.

## ما يعمل فعلًا

**شرارة:** منطق محلي محدد النوايا والحالات. يتابع النشاط والعنصر والمرحلة والاختيار والمحاولات والتلميحات والنتيجة والصوت والكاميرا، ويغير إرشاده عند تغيير العنصر دون مؤقتات حوار قديمة. النوايا غير المعروفة تعيد اقتراحات مرتبطة بالنشاط؛ ليس محادثة توليدية.

**الصوت:** تسجيل محلي إذا طابق النص حرفيًا؛ وإلا صوت عربي محلي بعد انتظار تحميل قائمة الأصوات. الأصوات التي تحتاج خدمة بعيدة مرفوضة. يُلغى الكلام القديم عند الانتقال أو إخفاء الصفحة. لا رسالة عطل قبل محاولة الاستماع، والنص متاح دائمًا. التسجيلات الحالية مولّدة مسبقًا وليست بشرية. لا ميكروفون شبكي.

**التصوير:** التقاط أو رفع، معاينة وإعادة التقاط، مطابقة تقليدية محلية، وتأكيد صريح. المراجع: ١٧ جهازًا، و٥ مناطق سلامة، و٩ مناطق مواد من الصفحات الموجودة؛ يستخدم نشاط الخامات ٨ منها. لا رفع صور أو نسبة ثقة مصطنعة أو إنشاء مجسم من الصورة. الصور الفارغة وغير الصالحة لا تنتج نجاحًا. الاختيار اليدوي دائمًا متاح، والبث يتوقف عند الالتقاط والإغلاق حتى مع إذن متأخر.

**AR/VR:** WebXR في نشاط الأجهزة فقط بعد فحص الدعم. AR يستخدم كشف سطح وتمركزًا ومقياسًا للمجسم وأزرار تجربة وخروج. VR يستخدم مؤشرًا وأزرارًا داخل المشهد، مع فصل اختيار المصدر عن تشغيله. بقية الأنشطة تعرض بديل الشاشة بصراحة.

## المحتوى والأصول الناقصة

- الطباشير عُزلت من تحدي الخامات لأن البيانات الأصلية تصنفها خشبًا؛ لم نغير تصنيفها بتخمين.
- موقف إصلاح السلك بالشريط عُزل من التقييم لحين مراجعة مرجع الكتاب والمختص؛ الوصف وحده لا يثبت سلامة الإصلاح.
- الموصلية نموذج لمواد جافة في دائرة افتراضية، وليست تعليمات لاستخدام مواد منزلية للحماية من الكهرباء.
- بعض العناصر بلا مرجع كتاب فردي واضح؛ تُختار يدويًا. إضافة المراجع والتسجيلات البشرية خطوة محتوى لاحقة.
- الحقوق محفوظة للباحثة ولاء حامد الصيداوي، وإشراف الدكتور حسن ربحي مهدي. التراخيص في `ATTRIBUTIONS.md`.

## الاختبارات والأدلة

الأوامر: `npm test`, `npm run test:browser`, `npm run test:camera`, `npm run test:xr`, `npm run build`.

- ١٧١ اختبار وحدة؛ منها ٢٦ جديدًا للحالة والتقييم والمساعدة والحفظ والمراجع.
- اختبار المتصفح يمر على الـ٥٩ عنصرًا: ١٧ جهازًا، ١٤ خامة، ١٣ موقفًا، ١٥ مادة؛ مع الخطأ وإعادة المحاولة والحفظ والصوت والسحب ولوحة المفاتيح والبديل المبسط.
- أحجام ١٤٤٠ و٧٦٨ و٣٩٠ و٣٢٠ بكسل: فحص التمرير الأفقي وأحجام الأزرار وتقليل الحركة.
- الكاميرا: إيقاف البث والرفض والإذن المتأخر والمعاينة والتأكيد والصور غير الصالحة والفارغة. مطابقة ناجحة لـ١٤ مرجعًا مكبّرًا ومدوّرًا من صفحات السلامة والموصلات، وصورة سيارة وغسالة مدوّرة. هذه ليست نسبة دقة ميدانية.
- الصوت: تشغيل وإيقاف تسجيل محلي فعلي؛ وفحوص اصطناعية لتأخر الأصوات وإلغاء الكلام القديم ورفض TTS البعيد.
- ١٢ تحققًا منطقيًا لـXR: تمركز واختيار وتشغيل وإيقاف وتبديل وخروج؛ **لم تتوفر نظارة أو هاتف AR للاختبار الفعلي**.

النتائج في `browser-results.json`, `camera-results.json`, `xr-results.json`. اللقطات في هذا المجلد، ومنها `home-desktop.png`, `home-mobile.png`, `materials-mobile.png`, `safety-mobile.png`, `camera-confirmation-mobile.png`.

## حدود التحقق

Chrome وأحجام الشاشات المحاكاة لا يعوضان اختبار Safari أو تابلت مدرسة فعلي. الكاميرا تستخدم بثًا اصطناعيًا؛ لم يُختبر وهج الورق أو إضاءة الصف أو تركيز هاتف. جودة الصوت المحلي تعتمد على الجهاز؛ قد يكون النص البديل. لم يُنفّذ نشر خارجي، ولا يوجد ادعاء بالعمل الكامل دون اتصال.

# سجل التصميم — ٩ أكتوبر ٢٠٢٦

المداخل الأصلية تعرض أربعة تطبيقات متشابهة، مع تنقل جانبي وعلوي مكرر ومساعد مختلف لكل نشاط. الأسماء والألوان تكشف بعض الإجابات، والمصدر مختار مسبقًا للسيارة. الرئيسية تعرض نشاطًا خامسًا غير متاح. الميكروفون لا يضمن المعالجة المحلية، ومطابقة السلامة والموصلات تستخدم الصفحة المرجعية نفسها لمعرفات متعددة.

## قرار التصميم

الموضوع هو مختبر الطفل: العنصر مركز الشاشة والأدوات بجواره. توقيع الواجهة طاولة بلا قاعدة ضخمة، وخيارات محايدة وشرارة صغير بجوار المحاولة. لا مقدمة بحثية أو إحصاءات تسويقية في رحلة الطفل.

- الحبر `#30283f`، البنفسجي `#7052a3`، البنفسجي الغامق `#4c3477`، الخلفية `#f8f7fb`، النعناع `#e6f2ed`، النجاح `#206447`.
- Tajawal المحلي 700 للعناوين والأفعال، 400 للتعليمات، وأرقام عربية للتقدم. لا تبعية خط جديدة أو تحميل شبكة.
- الرئيسية: أربع بطاقات لسطح المكتب، وبطاقتان في كل صف للموبايل.
- النشاط: المشهد يمينًا والإجابة وشرارة يسارًا. الهاتف: المشهد ثم الإجابة ثم المساعدة، بلا أدوات عائمة تغطي المحتوى.
- الاختيار إطار بنفسجي؛ الاكتمال علامة مكتوبة منفصلة. اللون لا يكشف الإجابة قبل المحاولة.

## المراحل

1. فحص البيانات والمشاهد والصوت والصور والحقوق.
2. استخراج قالب مشترك فوق البيانات والمجسمات الحالية، وتوحيد التقدم والمساعد.
3. انتقالات حالة واضحة، دائرة مرئية للموصلات، وبطاقة سحب مستقلة للفرز.
4. مدير صوت واحد، إلغاء الميكروفون الشبكي، وتصوير ومعاينة وتأكيد مع مراجع محددة لكل عنصر.
5. تحسين المسطرة والزجاج والكاميرا، وإزالة العلامات التي تكشف إجابات السلامة.
6. اختبارات وحدات ومتصفح وكاميرا وXR، ومراجعة لقطات الهاتف وإصلاح التفاف الرأس.

لم تُخترع أرقام صفحات أو إجابات منهجية. المراجع من الملفات الموجودة فعليًا تحت `assets/book`، ومناطقها في `references.js`. عُزل عنصران يحتاجان مراجعة محتوى، كما يوضح التقرير.
